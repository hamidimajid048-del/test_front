Key Findings

    Each login of B

    • One row per login of the emails B, measured against all the logins of email A in the same date range: its own evidence, the IPs and CIDs it shares with them, and whether it was active in the same period.
    • Evidence: Strong = a valid shared CID, or 3 or more shared IPs that are not VPN/proxy/Tor/datacenter. Medium = a shared IP that is not VPN/proxy/Tor/datacenter. Weak = only VPN/proxy/Tor/datacenter IPs or invalid CIDs are shared. None = nothing shared. It is a pointer for the reviewer, not a verdict.
    • The figures above the table compare all the logins of A with all the logins of B as two groups; the Linked pairs tab tells which login of A is linked to which login of B.
