  • Evidence: Strong = a valid shared CID, or 3 or more shared IPs that are not VPN/proxy/Tor/datacenter. Medium = a shared IP that is not VPN/proxy/Tor/datacenter. Weak = only VPN/proxy/Tor/datacenter IPs or invalid CIDs are shared. None = nothing shared. It is a pointer for the reviewer, not a verdict.
  • Shared IPs and CIDs: values used by at least one login of each email within the date range. Click a row to see its sessions in the Details tab.
  • Linked login pairs: which login of A shares how many IPs and CIDs with which login of B.
  • Details: every session of any login of both emails that used a shared IP or CID. Sorting, filters and paging apply to all rows.
